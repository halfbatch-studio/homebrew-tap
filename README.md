# Half Batch Homebrew tap

```sh
brew install halfbatch-studio/tap/shelfready
```

| Formula | What it is |
|---|---|
| `shelfready` | [ShelfReady](https://shelfready.dev): get iOS apps ready for the App Store (legal pages, privacy truth, go-live checklist). Installs `shelf` and `shelfready`. |

Formulas are updated automatically by each project's release workflow. Don't edit them here; open issues in the project's repository.
